# Runbook — incidente de segurança / dados pessoais

1. Contém e classifica no módulo `incidentes_seguranca` (Fase 8).
2. Avalia risco ao titular.
3. Aciona DPO; comunica ANPD/titulares conforme regulamentação vigente (**validar prazo com jurídico**; Res. CD/ANPD nº 15/2024 cita 3 dias úteis).
4. Registra linha do tempo e lições aprendidas.
