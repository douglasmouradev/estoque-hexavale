# ADR-0005 — Identidade visual “caderno de campo”

- Status: Aceito
- Data: 2026-10-18

## Contexto

Protótipo parecia SaaS genérico verde/Inter.

## Decisão

Tokens em `resources/css/tokens.css`. Fontes OFL (Barlow Condensed, Source Sans 3, IBM Plex Mono) self-hosted na Fase 1 (BK-FONT-01). Quatro componentes-assinatura.

## Consequências

+ Identidade própria; WCAG AA.
− Fontes ainda system-fallback na Fase 0.
